# Pandas Learning & Implementation

## Overview

This repository contains my hands-on learning and implementation of **Pandas**, a powerful Python library used for data analysis and data manipulation.

The purpose of this project is to strengthen my understanding of working with datasets through practical coding exercises and implementations.

## Topics Covered

* Reading CSV files
* Data Exploration
* Data Cleaning
* Handling Missing Values
* Filtering & Sorting Data
* Data Selection
* Data Manipulation
* Basic Data Analysis using Pandas

## Project Structure

```txt
phase-1.ipynb
phase-2.ipynb
phase-3.1.ipynb
phase-4.ipynb
```

Each phase contains practical implementations of different Pandas concepts learned during the learning process.
